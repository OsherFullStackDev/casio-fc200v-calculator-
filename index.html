FC-100V FINANCIAL CONSULTANT

מדריך מהיר

המחשבון עובד כמו ה-FC-100V: בוחרים מצב במקש המצב, גוללים ב-▲▼ בין המשתנים, מקלידים ערך ולוחצים EXE. כדי לחשב משתנה, עומדים עליו ולוחצים SOLVE.

מצבים

  • COMP – חישוב רגיל. Ans = התוצאה האחרונה.
  • CMPD – ריבית דריבית, משכנתאות והלוואות: n, I%, PV, PMT, FV, P/Y, C/Y. השורה Set מחליפה בין תשלום בסוף תקופה (End) לתחילתה (Begin).
  • SMPL – ריבית פשוטה: SI (ריבית) ו-SFV (סכום כולל).
  • CASH – תזרים מזומנים: NPV, IRR, PBP (תקופת החזר), NFV. ב-Csh לוחצים EXE כדי להזין תזרימים (CF0, CF1…), ו-ESC לחזרה.
  • AMRT – לוח סילוקין: יתרה (BAL), ריבית וקרן בתשלום PM1, וסכומים מ-PM1 עד PM2.
  • CNVR – המרה בין ריבית נומינלית (APR) לאפקטיבית (EFF). n = מספר צבירות בשנה.
  • COST – עלות (Cst), מחיר מכירה (Sel) ושיעור רווח (Mrg).
  • DAYS – ימים בין תאריכים. תאריך מוקלד כ-8 ספרות, למשל 01012026.
  • STAT – סטטיסטיקה: 1-VAR או רגרסיה ליניארית A+BX. מזינים נתונים ולוחצים SOLVE לתוצאות.

סימני כסף

כסף שמתקבל חיובי, כסף שמשולם שלילי. הלוואה של 200,000: PV=200000, והתשלום יצא שלילי.

מקשים מיוחדים

  • SHIFT + מקש = הפונקציה הכתומה שמעליו (למשל SHIFT AC = כיבוי, SHIFT SETUP = איפוס הכול).
  • ALPHA + מקש = המשתנה האדום (A, B, C, D, M).
  • SHIFT RCL (STO) ואחריו מקש משתנה שומר ערך. RCL ואחריו משתנה משחזר אותו.
  • SETUP – תשלום Begin/End, פורמט תאריך, שנה של 365/360 ימים ומספר ספרות אחרי הנקודה (Fix).
  • (−) = מספר שלילי. מינוס בתחילת הקלדה נחשב גם הוא לשלילי.

מקלדת

ספרות ופעולות, Enter = EXE, Backspace = DEL, Delete = AC, Esc = ESC, חיצים לניווט, S = SOLVE.

סימולטור עצמאי, ללא קשר ליצרנית המחשבון. הערכים נשמרים במכשיר.
