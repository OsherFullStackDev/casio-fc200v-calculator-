# מחשבון FC-100V

סימולטור בדפדפן של המחשבון הפיננסי Casio FC-100V. עובד בטלפון ובמחשב, אפשר להתקין אותו כאפליקציה (PWA), והוא עובד גם בלי אינטרנט.

## מה יש בו

| מצב | מה מחשב |
| --- | --- |
| COMP | חישובים רגילים: סוגריים, חזקות, שורשים, ln/log, אחוזים, זיכרון (A–D, M, Ans) |
| CMPD | ריבית דריבית / ערך הזמן של הכסף: n, I%, PV, PMT, FV, P/Y, C/Y, תשלום Begin/End |
| SMPL | ריבית פשוטה: SI, SFV (שנה של 365 או 360 ימים) |
| CASH | תזרים מזומנים: NPV, IRR, PBP, NFV |
| AMRT | לוח סילוקין: BAL, INT, PRN, ΣINT, ΣPRN |
| CNVR | המרה בין ריבית נומינלית לאפקטיבית |
| COST | עלות, מחיר מכירה ושיעור רווח |
| DAYS | ימים בין תאריכים |
| STAT | סטטיסטיקה של משתנה אחד ורגרסיה ליניארית A+BX |

השימוש כמו במכשיר: בוחרים מצב, גוללים ב-▲▼, מקלידים ערך ולוחצים EXE. כדי לחשב משתנה, עומדים עליו ולוחצים SOLVE. במסך עצמו יש כפתור "מדריך שימוש" עם הסבר מלא.

## הרצה מקומית

אין תלויות ואין שלב build. זה אתר סטטי:

```bash
npm start        # שרת על http://localhost:8080
npm test         # בדיקות (Node 20+)
```

## פריסה

כל שירות לאתרים סטטיים מתאים. ב-Vercel: Import לרפו, בלי Framework, בלי Build Command, Output Directory = `.`

## מבנה

- `src/math.js` – מנתח ביטויים ועיצוב מספרים לתצוגה
- `src/finance.js` – הנוסחאות הפיננסיות (לפי ההגדרות במדריך של FC-100V)
- `src/calculator.js` – מכונת המצבים של המחשבון: לחיצה ← מצב ← תצוגה של 4×16
- `src/keys.js` – פריסת המקשים
- `src/main.js` – חיבור ל-DOM, מקלדת ושמירה ב-localStorage

סימולטור עצמאי, ללא קשר ל-Casio.
